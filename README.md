# Eager Talent

## Requisitos

Para trabajar con el proyecto se necesita:

- Git
- Node.js 20 o superior
- Bun 1.2.20

No es necesario instalar PostgreSQL ni Docker para el desarrollo local.

## Desarrollo local

Luego de clonar el repositorio:

```bash
bun install
bun run setup:local
bun run dev
```

La aplicación queda disponible en: http://localhost:3000
